## 2. 审计分类

### Already Fixed

- 三个 Category/Node 已有唯一配置与同一采集入口；配件市场不是从高压清洗机榜单过滤伪造。
- `MARKET_CONFIG`、页面默认 Segment、URL parse/serialize/normalize 与 page-local 状态主干已经存在。
- Overview、Market、Products、Brands、Rankings 的主要数据路径已开始共享 `buildAnalyticalCategory` / `filterAnalyticalMarket`。
- Rankings 默认 `pressure_washers/all`，能够保留 Amazon Raw Top30。
- Shell 客户端请求缓存包含 `category:segment`，并有 AbortController。
- 最近不完整日不会直接生成 Exit；有效日比较已有基本保护。

### Partially Fixed

- Page-local context 已成立，但还没有 URL-local date；日期不能深链、刷新或导航继承。
- Brands 已读取 analytical category，但报告、Alerts/Seller Intelligence 仍只按 category 计算。
- ProductIdentity、RankDisplay、RankDelta 已存在，但部分页面仍自行格式化或把 rank 与 delta 粘连。
- AppShell 主导航已统一；Reports、Alerts、Methodology 内部内容仍残留旧工作台语言与交互。
- Data Status 有覆盖率，但没有 Latest Crawl / Snapshot / Valid Market Day 三分法。

### Still Broken

1. **分类规则冲突与误判**：兼容性文本中的 `gas/electric pressure washer` 会压过 `surface cleaner`；gun/nozzle 多命中直接退回 unknown；`electricity` 子串会误判 electric。典型错误包含 B0CJZWBTW9、B0BX4M63JF、B0CQML6RTV、B0CRNHHRDT、B085NBJB71、B085NMPT8L、B0HFM6BWG8。
2. **分类版本写入不一致**：D1 允许同置信度的更高规则版本替换旧值；PG migration 013 丢失了版本比较，旧 high/medium 无法被新版同置信度规则纠正，可能造成 PG 与 D1 Universe 分裂。
3. **详情跨市场混合**：`loadLiveProduct(asin)` 合并同 ASIN 的所有 category 历史，配件来源链接可能 404，时间线可能混合两个市场。
4. **Reports / Alerts Segment 误导**：路由验证并显示 Segment，但 builder 与归档实际只按 category 计算。
5. **Signal 链接丢上下文**：SignalCard 产品链接没有 category/segment。
6. **最近 Snapshot 选择错误**：全局最新 Snapshot 若某 category 不完整，分析会退化或 503，没有回落到该 category 的最近有效市场日。
7. **格式不统一**：reviews 使用 `zh-CN` compact；日期为中文；Deal 保留源字符串；RankDisplay 可产生 `#6—`。
8. **Overview 语义错误**：High KPI 统计 High+Watch；Brand Movement 可显示零变化。
9. **AnalysisCenter 竞态**：市场快速切换时旧请求可覆盖新市场；archive 分支引用未导入的 `categories`。

### Legacy Implementation

- Reports 仍以“智能报告/经营预警/竞争策略”为主要产品语言，未收口为 Daily Market Brief / Weekly Market Report。
- Alerts 仍使用旧卖家分析工作台结构，未完全复用 SignalCard，证据默认占据过多空间。
- Methodology 未完整覆盖 Raw/Analytical、Valid Day、Re-entry、Presence、Seat Share 与信号级别。

### Not Implemented

- URL-local Market Date 与 MarketDateSelect。
- Products 按当前市场动态显示 Electric/Gas/Cordless 或 Surface Cleaner/Gun/Hose/Nozzle/Other 类型过滤。
- 站点可查询的 crawl run/failure 状态及 Fresh/Delayed/Incomplete/Failed。
- 跨市场同 ASIN 详情隔离回归、反序请求缓存测试、三市场同 Universe 集合测试。

### Needs Refactor

- 分类判定需要“强产品类型短语 + 边界匹配 + 明确规则优先级”，不能继续依赖无边界 substring 与多命中全量 unknown。
- 分析入口需要接受完整 `MarketContext` 与有效日期，并统一通过一个 Market Universe builder。
- Product detail loader 需要 category-scoped history，并对 segment 做 Universe 校验。
- 显示函数需要集中为 rank/delta/reviews/rating/price/deal/date/percentage/missing。

## 3. 最高影响问题与迁移策略

1. 用回归 Fixture 固定分类语义，修规则与分类器。

6. 最后执行缓存反序、浏览器、多标签和截图 QA。
