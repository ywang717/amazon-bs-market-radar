# 浏览器按钮审计与报告页修复计划

## 目标

修复真实浏览器检查确认的无效报告按钮、市场切换丢失日期，以及报告归档把接口失败显示为空的问题；保留 Pacific Time、数据库和历史数据。

## 步骤

1. 修改报告归档状态模型，让接口非 2xx、JSON 失败和网络失败显示明确错误状态。
2. 将“全部报告⌄”改为可定位到报告归档的实际链接，并保留现有归档数据展示。
3. 市场切换保留当前有效日期参数。
4. 运行相关单元测试、静态检查和构建，检查 diff 与现有无关改动。
5. 发布到现有站点后，用云端浏览器重新点击导航、筛选、展开、详情、下载和归档入口，并检查 URL、页面内容、Console 与 Network。
