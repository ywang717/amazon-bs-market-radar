# V2.2 Final Intelligence Polish Implementation Plan

**Goal:** 在不改采集架构与历史快照的前提下，使三市场所有分析页面共享同一个有效日、市场 Universe、信号、趋势、格式与缓存语义，并完成规定的回归、截图和 Sites 发布。

**Spec:** `docs/superpowers/specs/2026-09-01-v2.2-final-intelligence-polish-design.md`

**Architecture:** 保留现有 Vinext Server Components、D1/R2、`live-dashboard-data.ts` 与 `market-context.ts`。在 `ui-intelligence.ts` 中建立纯函数 canonical contracts，页面和 Seller Intelligence 只消费这些合同，不再独立推导同类事实。无数据库迁移。

**Tech Stack:** TypeScript/React/Vinext、Node test runner、PowerShell/Pester、Cloudflare D1/R2、OpenAI Sites。

---

### Task 1 — Gate A canonical semantics

- 在 `web/tests/ui-intelligence.test.mjs` 先加入失败测试：仅三等级、Top10 entry/exit High、普通 entry/exit Activity、product+date+event 去重最高等级、失败 comparison 零信号。
- 在同一测试先加入优惠校验失败用例：合法优惠、reference 小于 current、负折扣、缺字段；原始值不变。
- 在 `web/tests/market-context.test.mjs` 加 cache key 的 marketplace/category/segment/date/window 隔离用例。
- 最小修改 `web/lib/ui-intelligence.ts` 与必要类型：建立 canonical signal ID/market date、三等级、显式去重、`validateDealDisplay`；保持旧调用点可渐进迁移。
- 运行 Gate A 定向测试；确认 RED 后实现到 GREEN。

### Task 2 — Gate B valid-day product and trend contracts

- 在 `web/tests/ui-intelligence.test.mjs` 先加入 Products 1D/7D/Presence、历史不足 `—`、失败日不进入分母的失败测试。
- 先加入 7D/30D 等长有效日窗口、Top10 stability、turnover、Top3 seat concentration、median price 与 neutral direction 的失败测试。
- 先加入品牌 7D seat trend、Others/Unknown 分离、Unknown 不产生 movement 的失败测试。
- 在 `web/lib/ui-intelligence.ts` 实现纯函数产品、市场和品牌趋势合同；只使用 category 已验证 history。
- 更新 `web/app/products/*`、`web/app/market/page.tsx`、`web/app/brands/page.tsx` 和首页，使其消费这些合同；快速筛选限制为 all/rising/falling/Top10/new/high presence。
- 更新 Seller Intelligence/Alerts/Reports 生成链，映射或直接消费 canonical signals，删除相同事实的第二套优先级推导；Reports 按摘要→High→Watch→Activity→Evidence→Methodology 展示，证据默认折叠。
- 运行 Gate B 定向测试和渲染测试。

### Task 3 — Gate C presentation consistency

- 先为共享 rank/delta/price/review/rating/percentage/date/deal/missing 格式、reentry/exit 文案、无效日期回落提示加入失败测试。
- 更新共享格式器和 `RankDisplay`/`SignalCard`/表格调用点；统一缺失为 `—`。
- `MarketContext` 保持一行紧凑显示并增加无效日期轻提示；导航继承当前上下文但不跨标签持久化。
- 仅整理 Methodology 导航/目录和折叠节点；统一术语与空状态。
- 运行 Gate C 定向测试与可访问性相关渲染断言。

### Task 4 — Regression, review and release

- 运行完整 Web 测试、PowerShell/Pester 测试、lint、type/build；任何失败按 systematic-debugging 追踪根因。
- 使用规定视口执行页面 QA：1366×768（Overview/Products/Rankings/Reports）、1440×900（Overview/Market/Brands/Alerts）、1920×1080（Overview/Reports），覆盖三市场并保存截图清单。
- 使用 `superpowers:requesting-code-review` 做最终只读审查，修复高/中风险问题并重跑相关测试。
- 使用 `superpowers:verification-before-completion` 重新验证最新代码状态。
- 使用现有 `web/.openai/hosting.json` 获取 Sites 凭据、保存精确源码版本、检查访问策略、部署并验证公开 URL。
