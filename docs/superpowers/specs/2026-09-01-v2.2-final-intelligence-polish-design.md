# V2.2 Final Intelligence Polish Design

本设计以用户提供的《Amazon BS Market Radar V2.2 Final Intelligence Polish》为批准规格。实现保持现有 Vinext/React + D1/R2 + PowerShell 抓取架构，不新增产品范围，不修改抓取源与历史快照。

核心数据流为：URL-local Market Context → Latest Valid Market Day → 独立 Market Universe → Canonical Signal Engine / Trend Windows → Overview、Market、Products、Brands、Alerts、Reports。所有页面使用同一类目、分群、日期和有效日历史；Raw Rankings 保留 Amazon 原始 Top30，Analytical 只使用严格分类后的市场。

Signal Engine 只有 High、Watch、Activity。Top10 entry/exit 与大幅排名变化为 High，中等排名变化为 Watch，普通 Top30 entry/exit 为 Activity；同 product+date+event 仅保留最高等级。失败或不完整日不参与比较。优惠展示使用非破坏性校验结果，不修改原始 observation。

趋势只按有效市场日计算。产品输出 1D、7D 和 Presence；市场输出 7D/30D 当前窗口与前一等长窗口的 Top10 稳定性、Turnover、Top3 席位集中度和中位价；品牌输出 7D 席位趋势、席位占比与 Top3 集中度，Others 与 Unknown 分离且 Unknown 不产生扩张/收缩结论。

页面只做紧凑信息架构与术语修正，不重做视觉系统。URL 是上下文真源；无效日期回落最近有效市场日并显示轻提示。共享格式器覆盖 rank、delta、price、reviews、rating、percentage、date、deal 与 missing。验证顺序严格为 Gate A、Gate B、Gate C、全量回归、规定视口截图 QA、生产构建和 Sites 发布。
