# Amazon BS Market Radar V3.0 第一阶段设计

## 目标

先修复 PRD 第一阶段的 P0/P1/P2 问题，确保分群分析、历史归档、报告筛选、价格变化和原始榜单说明使用真实数据并保持现有 D1、历史数据和 Pacific Time 口径不变。

## 范围

本阶段只处理：

1. 竞争观察在整机、配件和全部榜单分群下的实际 Top10 席位合同。
2. 卖家情报页面的错误分类和安全中文提示。
3. 报告及卖家情报归档的 segment 上下文，兼容不能可靠回溯分群的旧报告。
4. “全部报告⌄”真实的报告类型筛选行为。
5. 小额价格变化的精确展示和普通信号降噪。
6. 原始 Amazon Top30 结构模块的口径说明。
7. PRD 要求的第一阶段测试、真实浏览器回归和线上重新验证。

第二阶段的 Watchlist、竞品对比、信号聚合、自定义预警、研究清单、分群切换增强和数据状态中心另行设计，不与本阶段混合迁移。

## 设计

### 1. 实际席位合同

分析生成器继续使用当前分群过滤后的真实 observations，不补造排名。`rankingConcentration.top10Slots` 使用当前 observations 中 `rank <= 10` 的数量；`topStability` 同时记录当前与 baseline 的实际 Top10 席位数，并验证：

* 留存数不超过当前和 baseline 席位数的较小值。
* 当前日满足 `retained + entries = currentSlots`。
* baseline 日满足 `retained + exits = baselineSlots`。

合同类型新增 `currentTop10Slots` 和 `baselineTop10Slots`，旧报告读取时将缺失字段视为未知，不把旧报告伪装成分群报告。完整榜单仍可出现 10 个席位，分群报告允许少于 10 个。

### 2. 错误分类

卖家情报读取链路把错误归类为 `database`、`no_data`、`report_generation`、`contract` 或 `threshold`。公开 API 只返回稳定的中文安全错误码/提示，日志保留内部原因；不向浏览器暴露数据库、路径、密钥或堆栈。页面按错误类别显示下一步可理解的说明。

### 3. Segment 归档

新报告同步和存储使用 `marketplace/category/segment/marketDate` 作为分析上下文。优先在现有报告表增加可重复的 nullable `segment_key` 迁移，并把新报告键和查询带上 segment。旧报告不回填为 `machines`；无法可靠判断的旧报告显示“原始榜单历史报告”。PDF 对象路径保持兼容，历史对象不改写。

### 4. 报告筛选

报告归档筛选器使用 URL 查询参数保存 `kind=all|daily|weekly`，列表由真实 API 返回记录过滤。没有记录时显示对应空状态；按钮必须有选中状态和可键盘操作行为。segment、category、date 参数全部保留。

### 5. 价格变化

价格变化模型继续保存原始数值。展示层对绝对差额和百分比使用明确精度：低于 0.1% 的变化显示“变化幅度小于 0.1%”，并显示实际差额；这类变化只能生成普通市场动态，不得进入 High/Watch。

### 6. 原始 Top30 说明

保留原始榜单结构计算和数据。标题改为“Amazon 原始 Top30 商品结构”，并添加说明当前模块不受整机/配件分群筛选影响；当前分析卡片继续显示真实分群样本数。

## 测试与验收

* 合同单元测试覆盖当前/基线席位数分别为 10、少于 10、不同数量及空集合。
* 生成器测试确认不补造排名，entries/exits 与真实集合一致。
* 错误分类测试确认公开响应不泄漏内部细节。
* 归档迁移和查询测试确认新报告带 segment、旧报告保持未知口径。
* 报告筛选、价格显示、原始 Top30 文案和所有现有 UI 回归测试通过。
* 真实浏览器逐页验证首页、市场、榜单、产品、详情、品牌、报告、日报、周报、经营预警、竞争观察、历史归档、方法说明；覆盖三个类目、可用分群、日期切换、刷新、直接 URL、下载和错误/空数据状态。
* 通过后再部署，不修改生产数据库内容，不覆盖历史 PDF，不改变 Pacific Time 日期派生。

## 风险与边界

旧历史报告可能没有可验证 segment，只能显示为原始榜单历史报告。若线上 D1 schema 不支持迁移或无法安全回滚，先停止 segment 写入并保留旧读取路径，不执行 destructive 操作。第二阶段功能不在本设计的验收范围内。
