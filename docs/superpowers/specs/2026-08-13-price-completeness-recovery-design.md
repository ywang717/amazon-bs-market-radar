# Best Sellers 价格完整性复核与恢复设计

## 目标

每次 Amazon Best Sellers 抓取后，在导入数据库、生成报表和发送邮件之前，严格核查所有缺失价格。只有商品页面本身确实不公开价格时才允许保留空值；抓取故障、访问受限或原因不明的价格缺失不得进入下游流程。

## 完整性规则

- 每个启用分类必须包含全局排名 1–30，且排名和 ASIN 唯一。
- 每条记录必须具有排名、ASIN 和标题。
- 每个空价格必须经过商品详情页复核，并获得可审计的原因。
- 评分和评论数继续按现有采集契约保存；本功能不改变其业务可空规则。
- 已成功抓取的榜单价格直接保留，不重复访问详情页。

## 价格缺失复核

抓取榜单后，只对价格为空的 ASIN 打开对应商品详情页。详情页复核产生以下互斥结果：

1. `DETAIL_PRICE_FOUND`：详情页存在公开价格。使用详情页价格补全当前记录，并保存来源为详情页。
2. `PRICE_NOT_PUBLIC`：页面可正常读取，但明确处于无公开价格状态，例如当前不可购买、缺货、仅显示购买选项或需要登录才能查看价格。允许价格保持空值，报表继续以 `-` 显示，不额外标注。
3. `VERIFICATION_BLOCKED`：出现验证码、登录拦截、拒绝访问或浏览器错误。不能判定为商品本身无价格。
4. `PRICE_MISSING_UNEXPLAINED`：页面可访问，但既未找到价格，也未匹配到受支持的无公开价格证据。不能进入下游流程。

判定必须来自结构化页面信号或受控文本标记，不能仅以“选择器没找到价格”推断 `PRICE_NOT_PUBLIC`。

## 自动恢复与重抓

- 第一次完整性检查失败时，保存失败分类、ASIN、页面 URL、页面状态、缺失字段和原因代码。
- 对 `VERIFICATION_BLOCKED`、`PRICE_MISSING_UNEXPLAINED` 或分类结构不完整执行一次全新浏览器会话重抓；关闭原上下文，不复用缓存或用户配置。
- 第二次仍失败时再执行最后一次全新会话重抓。每次尝试都重新抓取三个完整分类，避免拼接不同时间点的榜单。
- 最多三次总抓取尝试（初次加两次恢复）。成功条件是三个分类均通过结构检查，且每个空价格均已归因或补全。
- 自动恢复仅使用预先实现并测试的选择器、页面重新加载、浏览器会话重建和详情页复核。无人值守运行不得自动修改源代码、安装依赖、绕过验证码或使用登录凭据。

## 运行边界与下游门禁

- 完整性检查和恢复属于 `Collect` 阶段；只有最终通过的快照才能覆盖当天规范快照。
- 未通过的尝试不得注册捕获回执、导入 PostgreSQL、生成报表、备份或发送邮件。
- 若当天已有有效快照，失败尝试不得覆盖它。
- 成功补全详情页价格后，规范快照保存补全后的价格；本设计不改变现有快照的对外字段结构。
- 商品本身无公开价格时，规范快照中的 `price` 保持 `null`，报表显示 `-`，不增加面向用户的原因标注。

## 诊断与审计

每次运行写入独立的价格完整性诊断 JSON，至少包含：

- 市场日期、运行时间、总尝试次数和最终状态；
- 每个分类的记录数、排名连续性、必填字段覆盖率和价格覆盖率；
- 每个初始缺价 ASIN 的榜单 URL、详情页 URL、最终原因代码、是否补全以及补全来源；
- 每次失败尝试的页面状态和安全错误类别；
- 不保存完整页面正文、Cookie、凭据、浏览器配置或其他敏感数据。

采集状态 JSON 增加完整性摘要和诊断文件路径，命令行结果返回最终尝试次数、价格复核计数和失败原因。诊断文件供故障排查使用，不进入正常日报正文。

## 错误处理

- 任何无法解释的空价格都视为抓取失败，而不是商品无价格。
- 详情页出现公开价格但解析失败时，视为 `PRICE_MISSING_UNEXPLAINED` 并触发重抓。
- 三次尝试后仍不完整，采集脚本返回非零退出码和机器可读错误；现有编排器停止所有下游步骤。
- 分类页面零记录、排名缺失、重复排名、重复 ASIN、分类错页、验证码和访问拒绝沿用严格失败行为，并纳入同一恢复次数限制。

## 测试与验收

- 使用真实结构的离线 HTML 测试榜单动态价格类、详情页公开价格以及各类无公开价格状态。
- 先验证失败测试能捕获旧选择器、未解释空价格和受阻详情页，再实现最小恢复逻辑。
- 测试详情页价格可补全、确认无公开价格可放行、未知缺失会失败并重试。
- 测试每次重试使用完整新会话和完整三分类结果，不混合多次尝试的数据。
- 测试最多三次、失败不覆盖既有快照、失败不进入回执/数据库/报表/邮件步骤。
- 完整项目测试必须零失败。
- 以真实 Amazon 页面进行只读验收：三类各 30 条，所有空价格均存在允许的复核原因，最终健康检查为 `HEALTHY`。

## 非目标

- 不绕过 Amazon 验证码、登录、访问限制或其他保护机制。
- 不使用用户 Amazon 账号或持久浏览器配置。
- 不允许运行时生成或修改抓取器源代码。
- 不回填既有历史快照中的价格。
- 不在正常日报中展示商品无价格的详细原因。
