# 庭院与花园监控

网站入口 `/garden`，次级页面为市场概览、产品监控和商机观察。美国站 Patio, Lawn & Garden 大类与 13 个官方一级分支各采集 Top 30；官方导航核验记录在 `config/garden-category-tree-evidence.json`。原有三个类目继续独立显示，旧报告批次仍可读取和同步。

采集及报告沿用 `Start-Amazon-BS-macos.sh` 的 DailyAuto、DailyImport 和 Weekly 模式。庭院与花园报告单独生成并跳过邮件，原有邮件范围保持不变。日期采用 America/Los_Angeles。采集完整性逐榜单验证真实排名 1–30 与 ASIN 唯一性；不同榜单中的同一 ASIN 汇总去重，保留所有归属。

页面使用近 90 天完整榜单，初筛计算使用最近 7 个完整市场日。排名、评论、评分及新入榜权重复用原模型；缺少品牌增长证据时不补造。产品自身历史和字段缺失降低置信度。至少 7 个完整市场日、置信度不低于 50%、初筛评分不低于 45 且有观察信号才列入自动候选。首日没有自动候选是预期行为，榜单不能推导真实销量。

## 核验和经济性

`/garden/review` 提供五维证据和逐项费用表单，高级明细可填写情景、来源和包含关系。同步凭证只驻留页面内存，不存入浏览器持久存储。报价、账单及实际经营数据须由有权限的人员核实，程序只能校验记录结构、日期与计算，不能认证外部凭证是否真实。

核算币种为 USD。金额采用十进制字符串和精确有理数运算，仅在显示时四舍五入至两位小数。批量金额除以件数；外币使用带来源和日期的换算率；比例费用按成交收入计算。单件净利润=售价－固定单件费用－售价×比例费用；盈亏平衡售价=固定单件费用÷(1－比例费用合计)。各项必须区分已核验、假设、缺失、不适用；不适用需要独立原因。已有报价包含的费用不重复扣减。

实际经营核算使用订单、账单或结算。新品预测可使用经人工核实的报价和官方费用工具，假设可以计算情景但不能确认为经济性已核验。关键费用缺失或来源失效时不输出完整利润。敏感性情景按原成本口径替换广告和退货金额或比例，均为预测。输入修改需新版本及重新人工确认，历史版本不可覆盖。

五维证据完整、经济性全部核验且利润为正，并由人工确认后才可标记值得进一步验证；这不是确定盈利承诺。

## 接口和兼容性

- `GET /api/public/garden-reviews`：最新已发布版本摘要，可按 asin/categoryKey 筛选。最新草稿会隐藏旧公开版本。只发布结论和核算摘要，不发布内部账单、报价、SKU、贸易条款。读取时重新检查来源时效。
- `GET /api/sync/v1/garden-reviews`：Bearer 同步认证，返回最新完整记录和版本列表。
- `POST /api/sync/v1/garden-reviews`：Bearer 同步认证，提交 marketplace、asin、categoryKey、revision、previousRevision、published、economicsInput、assessment。服务端重算经济性和实际市场资格；乐观版本检查确保并发冲突返回 409。

数据版本保存在 D1 `garden_review_versions`，旧表不清空。报告扩展到 18 个范围时使用 JSON 绑定保持单条原子写入并避开 D1 参数上限；原 4 范围批次继续兼容。纯榜单、未核验来源或缺失成本不会自动成为可靠商机。

验证：`cd web && npm test`、`npx tsc --noEmit --incremental false`、`npm run lint`；采集注册测试使用 `python3 -m unittest discover -s tests/python -p test_collector_registry.py`；macOS 导入兼容性测试使用 `pwsh -NoProfile -File tests/GardenPipelineSmoke.ps1`。

本次上线验证（2026-10-13）：Site 版本 16；17 个完整榜单共 510 条排名，庭院与花园 14 个榜单共 420 条、336 个去重产品；34 份 PDF 报告上传成功。授权访问下三个次级页面及公开核验接口返回 200。匿名直连仍可能被 Cloudflare 返回 403，未据此声明匿名浏览器验收通过。供应链真实凭证未提供，未创建任何生产商机核验结论。

部署使用现有 npm 依赖及 package-lock.json，移除造成 Sites 构建冲突的旧 pnpm-lock.yaml。保留用户原有未提交的开发锁文件。最终整体审查中，额外代理审查受账户额度限制，采用已有独立审查发现加自行审查和针对性回归；未合并主分支。
